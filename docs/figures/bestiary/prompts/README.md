# Bestiary card prompts

The image-generation house style for the Security Bestiary cards — the
late-1990s collectible "caged beast" cards in `../` (and their holo "Uncaged"
variant). Not a page of the docs site: a brief you use to generate more cards
in the same look.

- `bestiary-card-prompts.md` — the house style, the holo/anticipated variant,
  the per-card template, the art-prompt skeleton, and the production/tracking
  workflow. The *lore* each creature indexes (families, cages, keepers) lives
  in `../../../bestiary.md`; this is the visual how.

Companion to `../../framework/prompts/`, which holds the storybook *slide*
prompts (a different look). One `.md` per style.
